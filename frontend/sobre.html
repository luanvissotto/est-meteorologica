Estação Meteorológica Inteligente para Cidades Inteligentes

Projeto integrador de Ciência da Computação que une hardware ESP32, sensores ambientais, API Python e um dashboard público para cidadãos.

Os dados de temperatura, umidade, pressão, qualidade do ar, luminosidade e pluviometria são validados por faixas físicas e lógica proposicional antes de gerar estatísticas e alertas.

Como o sistema funciona

  1. O ESP32 lê DHT22, BMP280, MQ-135, LDR e o pluviômetro.
  2. O firmware valida faixas e envia JSON via HTTP ou MQTT.
  3. A API FastAPI autentica a estação, grava no SQLite/PostgreSQL e dispara alertas.
  4. O dashboard atualiza gráficos, mapa e indicadores automaticamente.
